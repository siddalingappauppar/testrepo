# EU Data Act — Implementation Guidelines

**Reference:** EDGB/2026/003-G
**Effective Date:** 2026-03-01

---

## G.1 Scope and Definitions

The EU Data Act 2026 applies to all organisations processing employee personal data within EU member states. Key definitions:

- **Data Controller**: The employer responsible for determining purposes and means of processing
- **Data Processor**: Any third party processing data on behalf of the employer
- **Personal Data**: Any information relating to an identified or identifiable natural person

## G.2 Compliance Timeline

| Milestone | Deadline |
|---|---|
| Initial self-assessment | 2026-04-01 |
| Data mapping completed | 2026-05-01 |
| Technical measures implemented | 2026-06-01 |
| First compliance report | 2027-01-31 |

## G.3 Key Implementation Steps

1. Conduct a data audit to identify all employee personal data held
2. Appoint a Data Protection Officer (DPO) if processing exceeds **500 employee records**
3. Implement technical and organisational measures per Annex A standards
4. Establish a breach notification procedure per Article 7 timelines

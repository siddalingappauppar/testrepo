# Annex B — Reporting Deadlines and Filing Windows

**Parent Regulation:** EU Data Act EDGB/2026/003
**Effective Date:** 2026-03-01

---

## B.1 Annual Compliance Report

All covered employers must submit an Annual Data Compliance Report by **31 March** of each year, covering the preceding calendar year.

The report must include:

- Number of data access requests received and response times
- Summary of any data breaches and remediation actions
- Confirmation of ongoing data centre certification status
- Employee count and jurisdictions covered

## B.2 Breach Notification Timeline

| Event | Deadline |
|---|---|
| Internal detection | Immediately |
| Supervisory authority notification | Within **72 hours** |
| Affected employee notification | Within **7 days** |
| Full incident report submission | Within **30 days** |

## B.3 Employee Data Request Response Window

Employers must acknowledge employee data access requests within **5 business days** and provide the full data package within **30 days**. For complex requests, a one-time extension of **15 days** is permitted with written notice to the employee.

## B.4 Penalty Assessment Deadlines

The supervisory authority will issue penalty notices within **90 days** of confirmed non-compliance. Employers have **30 days** from the notice date to appeal or pay the assessed penalty.
